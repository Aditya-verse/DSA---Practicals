4) THEORY
--------------------------------------------------------------------
Graph:
A graph is a non-linear data structure consisting of vertices
(nodes) and edges (connections). In this practical, landmarks
represent vertices and the roads connecting the landmarks represent
edges.

Adjacency Matrix:
An adjacency matrix is a two-dimensional array used to represent a
graph. If an edge exists between two vertices, the corresponding
matrix entry is 1; otherwise, it is 0.

For an undirected graph, the matrix is symmetric, because an edge
from vertex A to vertex B also connects B to A.

Depth First Search (DFS):
DFS is a graph traversal technique that explores one path as deeply
as possible before backtracking. It can be implemented using
recursion or a stack.

The algorithm marks each visited vertex to avoid visiting it
repeatedly, and then recursively explores its unvisited adjacent
vertices.

Applications:
   1) Exploring connected locations.
   2) Detecting cycles in graphs.

6) ALGORITHM  (draft)
--------------------------------------------------------------------
Step 1 : Start the program.
Step 2 : Read the number of landmarks and their names.
Step 3 : Create an adjacency matrix of size V x V and initialize all
         entries to 0.
Step 4 : Enter the connections between landmarks and set the
         corresponding matrix entries to 1 (symmetric for an
         undirected graph).
Step 5 : Initialize the visited array, marking all vertices as
         unvisited.
Step 6 : Select the starting landmark.
Step 7 : Call DFS for the starting vertex.
Step 8 : In DFS(v): mark v as visited and display it.
Step 9 : For every vertex u in the row of v, if the matrix entry is 1
         and u is unvisited, call DFS(u) recursively.
Step 10: When no unvisited adjacent vertex remains, backtrack to the
         previous call.
Step 11: Stop.


7) TIME COMPLEXITY  (draft)
--------------------------------------------------------------------
   - Time complexity  : O(V^2), because for every vertex the whole
                        row of the adjacency matrix is scanned.
   - Space complexity : O(V^2) for the adjacency matrix, plus O(V)
                        for the visited array and the recursion
                        stack.
