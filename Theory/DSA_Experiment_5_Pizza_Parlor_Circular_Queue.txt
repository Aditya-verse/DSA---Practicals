EXPERIMENT 5
Pizza Parlor Order Management Using Circular Queue
====================================================================

1) AIM
--------------------------------------------------------------------
To implement a circular queue using an array for simulating a Pizza
Parlor order management system, where orders are accepted and served
on a First Come First Served (FCFS) basis.


2) PROBLEM STATEMENT
--------------------------------------------------------------------
Write a C++ program to simulate a Pizza Parlor order management
system using a circular queue. The Pizza Parlor can accept a maximum
of M orders. Each order is stored in the queue and served according
to the FCFS principle.

The system should perform the following operations:
   1) Accept a new pizza order.
   2) Serve / deliver pizza orders.
   3) Display pending orders.
   4) Check whether the queue is full.
   5) Check whether the queue is empty.


3) OBJECTIVE
--------------------------------------------------------------------
   - To understand the concept of a circular queue.
   - To implement a circular queue using an array.
   - To perform insertion and deletion operations in a circular
     queue.
   - To understand the FIFO principle in a queue.
   - To manage pizza orders according to FCFS.
   - To check whether the queue is full or empty.
   - To display the pending orders in the queue.
   - To understand the efficient use of queue memory using a
     circular queue.


4) THEORY
--------------------------------------------------------------------
A circular queue is a queue in which the last position is connected
to the first position. It follows the FIFO (First In First Out)
principle.

In this program, a circular queue is used to manage pizza orders in
a Pizza Parlor. The orders are inserted from the rear and served
from the front.

The two important pointers used are:
   - Front : Points to the first order in the queue.
   - Rear  : Points to the last order in the queue.

The next position in a circular queue is calculated using:

        (index + 1) % size

The queue is full when:
        front == (rear + 1) % size

The queue is empty when:
        front == -1


5) ALGORITHM
--------------------------------------------------------------------
1) Start the program.
2) Define a circular queue using an array and initialize front and
   rear to -1.
3) Display the Pizza Parlor menu.
4) Accept the user's choice.
5) If the choice is Accept Order:
      - Check whether the queue is full.
      - If the queue is full, display "No more orders".
      - Otherwise, insert the new order at the rear.
      - Update the rear position using circular increment.
6) If the choice is Make Payment / Serve Order:
      - Check whether the queue is empty.
      - If the queue is empty, display "Orders is not there".
      - Otherwise, remove the order from the front.
      - Update the front position.
      - Display the delivered order and calculate the total amount.
7) If the choice is Pending Orders:
      - Check whether the queue is empty.
      - If empty, display "There is no pending order".
      - Otherwise, traverse the queue from front to rear and
        display all pending orders.
8) Repeat the process until the user selects Exit.
9) Stop the program.
