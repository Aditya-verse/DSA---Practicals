4) THEORY
--------------------------------------------------------------------
A Binary Search Tree (BST) is a binary tree in which values smaller
than a node are stored in its left subtree, while values greater
than a node are stored in its right subtree.

Structure of a Binary Search Tree:

Consider inserting the values 50, 30, 70, 20, 40, 60, 80 into an
initially empty BST.

                     (50)
                    /    \
                 (30)    (70)
                 /  \    /  \
              (20) (40) (60) (80)

   Left subtree of 50 : 30, 20, 40
   Right subtree of 50: 70, 60, 80

Operations Performed:

1) Insertion of a new node
   To insert a new value, start from the root. If the value is
   smaller than the current node, move to the left subtree. If it is
   greater, move to the right subtree. Insert the new node at the
   first empty position found.

2) Finding the longest path from the root
   The longest path from the root to a leaf is determined by the
   height of the tree. The height can be calculated recursively:

        H(T) = 1 + max( H(TL), H(TR) )

   Here, TL and TR represent the left and right subtrees.

3) Finding the minimum data value
   In a BST, the minimum value is found by repeatedly moving to the
   left child from the root until no further left child exists. The
   leftmost node contains the minimum value. If the root has no left
   child, then the root itself contains the minimum value. This
   operation takes O(h) time, where h is the height of the tree.
